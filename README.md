# COD+ 2026 - Yeni Nesil İnteraktif Yazılım Eğitimi & Kodlama Platformu

🚀 **COD+ 2026**, modern yazılım geliştiricileri için sıfırdan ileri seviyeye kadar tasarlanmış, interaktif yılan harita (roadmap), 5 programlama dili (HTML/Web, SQL, Python, C#, C++), 150 kapsamlı ders, 10 soruluk Seviye Tespit Sınavı, çok dilli konsol/tarayıcı motoru, akran düellosu ve dijital kitap kütüphanesi içeren gelişmiş bir web platformudur.

---

## 🛠️ VS Code ile Çalıştırma (Hızlı Başlangıç)

1. **Visual Studio Code**'u açın.
2. `Dosya` > `Klasör Aç...` (File > Open Folder...) menüsünden **Masaüstünüzdeki `COD+2026`** klasörünü seçin.
3. Sol taraftaki dosya listesinden `index.html` dosyasına sağ tıklayın ve **"Open with Live Server"** seçeneğini seçin (veya klavyeden `Alt + L, Alt + O` tuşlarına basın).
4. `index.html` dosyasını doğrudan herhangi bir web tarayıcısına (Chrome, Edge, Firefox) çift tıklayarak da çalıştırabilirsiniz.

## 🌟 Öne Çıkan Özellikler

1. **5 Farklı Programlama Dili & 150 Müfredat Dersi:**
   - **HTML / CSS / JavaScript:** Web temelleri, DOM, dinamik arayüzler (30 ders).
   - **SQL:** SELECT, WHERE, CREATE TABLE, DDL/DML, JOIN, GROUP BY, Transactions (30 ders).
   - **Python 3:** Değişkenler, döngüler, veri yapıları, OOP, dosya yönetimi (30 ders).
   - **C# (.NET 9):** Tip güvenliği, diziler, metotlar, LINQ, OOP mimarisi (30 ders).
   - **C++ (C++20):** I/O akışları, işaretçiler, bellek yönetimi, STL, Templates (30 ders).

2. **10 Soruluk Kalibre Edilmiş Seviye Tespit Testi:**
   - Kullanıcının önceki bilgi seviyesini 10 aşamalı soruyla ölçer.
   - **9-10 Doğru:** İlk 20 temel ve orta dersi muaf sayar, doğrudan **21. İleri Seviyeden** başlatır!
   - **7-8 Doğru:** 15. Seviyeden başlatır.
   - **5-6 Doğru:** 11. Seviyeden (2. Bölüm) başlatır.
   - **3-4 Doğru:** 6. Seviyeden başlatır.
   - **0-2 Doğru:** Eksiksiz öğrenim için 1. Seviyeden başlatır.

3. **Özel Glassmorphism Giriş Modalı:**
   - Google ve Apple ile girişlerde tarayıcı `prompt()` uyarısı tamamen kaldırılmıştır.
   - Doğrulanmış e-posta, kullanıcı adı, eğitim düzeyi ve mentörlük hedefleri şık COD+ arayüzü ile alınır.

4. **10 Dakikalık Akıllı Kod Çıktı Süre Sınırı:**
   - Ders çalışma, quiz çözme veya dijital kitap okuma sırasında ekran asla kapanmaz veya kullanıcıyı haritaya atmaz.
   - Yalnızca IDE'de sonsuz döngü veya aşırı işlemci tüketimini önlemek için 10 dakikalık arka plan koruma sayacı çalışır.

5. **Akran Düelloları & Çok Dilli Serbest Çalışma Alanı (Sandbox):**
   - Seçilen dile özel syntax ve çıktı motoru (HTML Renderer, SQL Query Engine, Python 3.12, .NET 9 CLR, GCC C++20).
   - Arkadaşlarla canlı rekabet ve XP / Elmas kazanım sistemi.
